# 故障树编辑器使用说明

## 功能概述

这是一个可实时编辑的故障树可视化工具，支持节点文本编辑、添加/删除节点、保存/加载故障树等功能。

## 基本操作

### 查看模式（默认）
- **切换故障树**: 按数字键 1/2/3
- **平移视图**: 鼠标拖拽
- **缩放视图**: 鼠标滚轮
- **适应画布**: 按 F 键
- **动态画布**: 按 D 键

### 编辑模式（按 E 键切换）
- **选择节点**: 左键点击节点
- **编辑文本**: 双击节点进入编辑模式
- **删除节点**: 选中节点后按 Delete 键
- **添加节点**: 右键点击空白区域
- **节点操作**: 右键点击节点显示菜单
- **退出编辑**: 按 Escape 键

## 节点类型

1. **基本事件** - 圆形节点，表示基本故障事件
2. **与门** - 半圆+矩形，表示所有子事件同时发生
3. **或门** - 椭圆形状，表示任一子事件发生
4. **转移门** - 三角形，表示转移到其他故障树

## 文件操作

- **保存故障树**: 点击"保存故障树"按钮，下载JSON文件
- **加载故障树**: 点击"加载故障树"按钮，选择JSON文件

## 编辑功能详细说明

### 文本编辑
1. 按 E 键进入编辑模式
2. 双击任意节点
3. 在弹出的输入框中修改文本
4. 按 Enter 保存或 Escape 取消

### 添加节点
1. 进入编辑模式
2. 右键点击空白区域
3. 选择要添加的节点类型（1-4）
4. 新节点将添加到根节点下

### 删除节点
1. 进入编辑模式
2. 左键点击要删除的节点（节点会变红高亮）
3. 按 Delete 键确认删除
4. 注意：无法删除根节点

### 保存和加载
- 保存的文件是JSON格式，包含完整的故障树结构
- 加载时会替换当前显示的故障树
- 建议在编辑前先保存当前工作

## 技术特性

- 实时坐标转换和点击检测
- 递归节点查找和位置计算
- JSON序列化/反序列化
- 动态布局重新计算
- 跨浏览器兼容性

## 注意事项

1. 编辑模式下，节点选择会阻止画布拖拽
2. 删除节点会立即生效，请谨慎操作
3. 保存的文件名包含故障树ID
4. 加载文件时会替换当前故障树，建议先保存
